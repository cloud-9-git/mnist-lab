# `src/` 쉬운 코드 설명서

이 문서는 `src/` 폴더 안의 코드가 무엇을 하는지, 처음 보는 사람도 따라갈 수 있게 설명한 문서다.

딥러닝이나 NumPy에 익숙하지 않아도 괜찮다.  
핵심은 "이미지를 숫자로 바꾸고, 그 숫자를 여러 계산 단계에 통과시켜 정답을 맞히게 만든다"는 흐름을 이해하는 것이다.

## 1. 이 프로젝트는 무엇을 하나?

이 프로젝트는 **손글씨 숫자 이미지(MNIST)** 를 보고, 그것이 `0`부터 `9` 중 무엇인지 맞히는 프로그램이다.

예를 들어:

- 사람이 보면 "이건 7이네"라고 바로 알 수 있다.
- 컴퓨터는 이미지를 바로 이해하지 못한다.
- 그래서 이미지를 `28 x 28` 픽셀에서 `784`개의 숫자로 펼친 뒤,
- 그 숫자들을 여러 층(layer)에 통과시키며 "이 숫자가 0일 확률", "1일 확률" ... "9일 확률"을 계산한다.

## 2. 전체 흐름 먼저 보기

이 프로젝트의 큰 흐름은 아래와 같다.

1. `data.py`에서 MNIST 데이터를 불러온다.
2. `network.py`에서 신경망 모델을 만든다.
3. `training.py`의 `train()`이 학습을 반복한다.
4. 학습할 때는:
   - `forward()`로 예측을 만들고
   - `loss`로 얼마나 틀렸는지 계산하고
   - `backward()`로 어느 방향으로 고쳐야 하는지 gradient를 구하고
   - `optimizer`가 실제 숫자들(가중치)을 업데이트한다.
5. 학습이 끝나면 `evaluate()`로 정확도를 확인한다.

쉽게 말하면:

- `forward` = "지금 내 답은 뭐지?"
- `loss` = "얼마나 틀렸지?"
- `backward` = "어느 부분을 얼마나 고쳐야 하지?"
- `update` = "실제로 값을 고친다"

## 6. `src/activations.py`

이 파일에는 **활성화 함수**가 있다.

활성화 함수는 신경망이 단순한 선형 계산만 하지 않도록 만들어 준다.  
쉽게 말하면 "중간에 성격을 바꿔주는 규칙"이다.

## `class ReLU`

ReLU는 아주 자주 쓰이는 활성화 함수다.

규칙은 단순하다:

- 양수는 그대로 둔다.
- 0 이하 값은 0으로 만든다.

예:

```python
[-2, 3, 0, 5] -> [0, 3, 0, 5]
```

### `forward(self, x)`

### 기능

입력값을 ReLU 규칙에 따라 바꾼다.

### 어떻게 동작하나?

1. `x > 0`인 위치를 기록한다.
2. 양수는 그대로 두고, 0 이하 값은 0으로 만든다.
3. 결과를 반환한다.

### 왜 위치를 기록하나?

나중에 `backward()`에서 gradient를 흘려보낼 때,
"어디가 살아 있었고 어디가 꺼졌는지" 알아야 하기 때문이다.

### `backward(self, dout)`

### 기능

ReLU를 통과했던 gradient를 이전 층으로 되돌려 보낸다.

### 어떻게 동작하나?

1. forward 때 양수였던 위치만 gradient를 통과시킨다.
2. 음수였던 위치는 gradient를 0으로 만든다.

### 쉽게 말하면

- forward에서 꺼진 뉴런은
- backward에서도 gradient를 전달받지 못한다.

### 한 줄 요약

- "양수만 살리고, 음수는 끄는 활성화 함수"

## `class Softmax`

Softmax는 마지막 출력층에서 사용된다.

이 함수는 "점수"를 "확률처럼 보이는 값"으로 바꿔준다.

예를 들어:

```python
[2.1, 0.3, 5.7]
```

같은 점수가 들어오면,

```python
[0.026, 0.004, 0.970]
```

처럼 각 클래스의 확률 비슷한 값으로 바뀐다.

### `forward(self, x)`

### 기능

각 클래스 점수를 확률 분포로 바꾼다.

### 어떻게 동작하나?

1. 각 행에서 가장 큰 값을 먼저 빼 준다.
   - 이유: 너무 큰 숫자 때문에 계산이 터지는 것을 막기 위해서다.
2. `exp()`를 취해 모든 값을 양수로 만든다.
3. 각 행의 총합으로 나눠 합이 1이 되게 만든다.

### 결과는 어떤 의미인가?

출력의 각 값은 "이 숫자일 가능성"처럼 해석할 수 있다.

### `backward(self, dout)`

### 기능

현재 구조에서는 gradient를 직접 계산하지 않고, 받은 값을 그대로 넘긴다.

### 왜 그대로 넘기나?

이 프로젝트에서는 `Softmax + Cross Entropy`를 묶어서 `train()`에서 gradient를 직접 만든다.  
그래서 여기서는 별도 계산 없이 전달만 해도 된다.

### 한 줄 요약

- "마지막 점수를 확률처럼 바꿔주는 함수"

## 7. `src/layers.py`

이 파일은 신경망을 이루는 기본 레이어들을 담고 있다.

레이어는 쉽게 말하면 "데이터가 지나가는 계산 칸"이다.

## `class Affine`

Affine은 완전연결층(Fully Connected Layer)이다.

수식은 다음과 같다.

```python
y = xW + b
```

여기서:

- `x`: 입력
- `W`: 가중치
- `b`: 편향

### 왜 필요한가?

입력 데이터를 다른 차원으로 바꾸고, 학습 가능한 계산을 하게 만든다.

예를 들어:

- 입력 `784`개를 받아
- 중간층 `512`개 특징으로 바꾸는 역할을 한다.

### `__init__(self, W, b)`

### 기능

가중치 `W`와 편향 `b`를 저장한다.

### `forward(self, x)`

### 기능

입력을 선형 변환해서 다음 층으로 보낸다.

### 어떻게 동작하나?

1. 입력 `x`를 2차원 형태로 정리한다.
2. backward에서 쓰기 위해 `x`를 저장한다.
3. `x @ W + b`를 계산한다.

### `backward(self, dout)`

### 기능

이 레이어의 gradient를 계산한다.

### 어떻게 동작하나?

1. `dW`를 계산한다.
2. `db`를 계산한다.
3. 이전 층으로 보낼 `dx`를 계산한다.

### 왜 `dW`, `db`가 중요한가?

optimizer가 이 값을 보고 `W`, `b`를 실제로 바꾼다.

### 한 줄 요약

- "입력을 가중치와 편향으로 계산해 다음 층으로 보내는 선형 레이어"

## `class BatchNorm`

BatchNorm은 Batch Normalization의 줄임말이다.

이 레이어는 입력값의 분포를 정리해 학습을 좀 더 안정적으로 만들어 준다.

쉽게 말하면:

- 값이 너무 크거나 너무 치우치면 학습이 불안정해질 수 있다.
- BatchNorm은 값을 적당한 범위로 맞춰 주는 보정 장치다.

### `__init__(self, gamma, beta, momentum=0.9)`

### 기능

정규화 후 다시 크기와 위치를 조정하기 위한 파라미터를 저장한다.

### 주요 변수

- `gamma`: 정규화 후 크기 조정
- `beta`: 정규화 후 위치 조정
- `running_mean`, `running_var`: 테스트 때 사용할 누적 통계

### `forward(self, x, train=True)`

### 기능

입력을 정규화해서 더 안정적인 분포로 바꾼다.

### 학습 때는 어떻게 동작하나?

1. 현재 배치의 평균을 구한다.
2. 현재 배치의 분산을 구한다.
3. 평균을 빼고 표준편차로 나눠 정규화한다.
4. `gamma`와 `beta`를 적용한다.
5. 나중에 테스트 때 쓸 `running_mean`, `running_var`를 갱신한다.

### 테스트 때는 어떻게 동작하나?

학습 때처럼 현재 배치 평균을 쓰지 않고,
지금까지 저장해 둔 `running_mean`, `running_var`를 쓴다.

### 왜 train/test를 다르게 하나?

테스트할 때는 배치가 매번 달라져도 결과가 흔들리지 않도록,
학습 중 쌓아 둔 평균적인 통계를 사용해야 하기 때문이다.

### `backward(self, dout)`

### 기능

정규화 과정 전체를 거꾸로 따라가며 gradient를 계산한다.

### 계산되는 값

- `dbeta`: `beta`의 gradient
- `dgamma`: `gamma`의 gradient
- `dx`: 이전 층으로 전달할 gradient

### 한 줄 요약

- "입력값 분포를 정리해서 학습을 안정화하는 레이어"

## `class Dropout`

Dropout은 학습 중 일부 뉴런을 무작위로 꺼 버리는 기법이다.

### 왜 필요한가?

모델이 특정 패턴에만 과하게 의존하는 것을 줄여서 과적합을 막기 위해서다.

쉽게 말하면:

- 공부할 때 매번 같은 힌트만 보지 못하게 만드는 장치다.

### `__init__(self, drop_ratio=0.5)`

### 기능

몇 퍼센트의 뉴런을 끌지 저장한다.

### `forward(self, x, train=True)`

### 학습 때는 어떻게 동작하나?

1. 무작위 마스크를 만든다.
2. 일부 뉴런을 0으로 만든다.
3. 살아남은 값만 다음 층으로 보낸다.

### 테스트 때는 어떻게 동작하나?

테스트 때는 뉴런을 실제로 끄지 않는다.  
대신 평균 크기를 맞추기 위해 `(1 - drop_ratio)`만큼 곱해 준다.

### `backward(self, dout)`

### 기능

forward 때 살아남은 뉴런에만 gradient를 보낸다.

### 한 줄 요약

- "학습 중 일부 뉴런을 랜덤하게 꺼서 과적합을 줄이는 레이어"

## 8. `src/losses.py`

이 파일은 손실 함수(loss function)를 담고 있다.

손실 함수는 "얼마나 틀렸는지"를 숫자로 알려준다.

## `cross_entropy_loss(y_pred, y_true)`

### 기능

분류 문제에서 예측이 얼마나 틀렸는지 계산한다.

### 입력

- `y_pred`: 모델이 낸 확률들
- `y_true`: 정답 라벨

### 어떻게 동작하나?

1. 각 샘플에서 정답 클래스의 확률만 뽑는다.
2. 그 확률에 `-log()`를 취한다.
3. 배치 평균을 낸다.

### 해석

- 정답 확률이 높으면 loss가 작다.
- 정답 확률이 낮으면 loss가 크다.

예를 들어:

- 정답인데 확률이 `0.99`면 잘한 것
- 정답인데 확률이 `0.10`이면 많이 틀린 것

### 한 줄 요약

- "모델이 얼마나 틀렸는지 숫자로 알려주는 함수"

## 9. `src/optimizers.py`

이 파일은 파라미터를 실제로 고치는 규칙을 담고 있다.

gradient를 구하는 것만으로는 학습이 끝나지 않는다.  
그 gradient를 이용해서 `W`, `b` 같은 값을 바꿔야 한다.

## `class SGD`

SGD는 가장 단순한 optimizer다.

### `__init__(self, lr=0.01)`

### 기능

학습률 `lr`을 저장한다.

### 학습률이란?

한 번에 얼마나 크게 움직일지를 정하는 값이다.

- 너무 크면 학습이 흔들릴 수 있다.
- 너무 작으면 학습이 너무 느리다.

### `update(self, params, grads)`

### 기능

각 파라미터를 gradient의 반대 방향으로 조금 이동시킨다.

### 어떻게 동작하나?

각 파라미터마다:

```python
params[key] -= lr * grads[key]
```

를 수행한다.

### 한 줄 요약

- "기울기의 반대 방향으로 조금씩 이동하는 가장 기본적인 optimizer"

## `class Adam`

Adam은 SGD보다 보통 더 안정적이고 빠르게 학습되는 optimizer다.

### 아이디어

Adam은 단순히 지금 gradient만 보는 것이 아니라,

- 최근 gradient의 평균
- 최근 gradient 크기의 평균

을 함께 참고해서 업데이트한다.

### `__init__(self, lr=0.001)`

### 기능

학습률과 내부 상태를 초기화한다.

### 내부 상태

- `m`: gradient의 평균 비슷한 값
- `v`: gradient 제곱의 평균 비슷한 값
- `t`: 현재 몇 번째 업데이트인지 기록

### `update(self, params, grads)`

### 기능

Adam 규칙에 따라 각 파라미터를 업데이트한다.

### 어떻게 동작하나?

1. step 수를 1 증가시킨다.
2. `m`, `v`를 갱신한다.
3. 초기 단계의 치우침을 보정한다.
4. 보정된 값으로 파라미터를 업데이트한다.

### 한 줄 요약

- "gradient의 최근 흐름까지 고려해서 더 똑똑하게 업데이트하는 optimizer"

## 10. `src/network.py`

이 파일은 신경망 전체를 조립한다.

지금까지 설명한 작은 부품들:

- Affine
- BatchNorm
- ReLU
- Dropout
- Softmax

을 하나의 모델로 묶는 파일이다.

## `class NeuralNetwork`

이 클래스가 사실상 "모델 전체"다.

기본 구조는 다음과 같다.

```text
입력 784
-> Affine(512)
-> BatchNorm
-> ReLU
-> Dropout
-> Affine(256)
-> BatchNorm
-> ReLU
-> Dropout
-> Affine(10)
-> Softmax
```

### `__init__(self, use_batchnorm=True, use_dropout=True, dropout_ratio=0.5)`

### 기능

모델에 필요한 숫자들(파라미터)과 레이어 순서를 준비한다.

### 어떻게 동작하나?

1. BatchNorm, Dropout을 쓸지 여부를 저장한다.
2. `W1`, `W2`, `W3`, `b1`, `b2`, `b3`를 만든다.
3. 필요하면 `gamma1`, `beta1`, `gamma2`, `beta2`도 만든다.
4. 레이어를 순서대로 `OrderedDict`에 넣는다.
5. gradient를 저장할 `self.grads`를 준비한다.

### 왜 `OrderedDict`를 쓰나?

forward와 backward에서 **순서를 정확히 유지**해야 하기 때문이다.

### `forward(self, x, train=True)`

### 기능

입력을 처음부터 끝까지 통과시켜 최종 예측을 만든다.

### 어떻게 동작하나?

1. 입력 `x`를 받는다.
2. 레이어를 앞에서부터 차례대로 지난다.
3. 최종적으로 `10`개 숫자 클래스에 대한 확률을 만든다.

### 출력은 무엇인가?

각 숫자일 가능성을 담은 배열이다.

예:

```python
[0.01, 0.02, 0.90, 0.01, ...]
```

이면 "2일 확률이 가장 높다"는 뜻이다.

### `backward(self, dout)`

### 기능

출력층에서 시작해 거꾸로 gradient를 계산한다.

### 어떻게 동작하나?

1. 레이어를 뒤에서부터 역순으로 돈다.
2. 각 레이어의 `backward()`를 호출한다.
3. `Affine`의 `dW`, `db`를 모은다.
4. BatchNorm을 쓴 경우 `dgamma`, `dbeta`도 모은다.
5. optimizer가 쓸 `self.grads`를 완성한다.

### `loss(self, x, y)`

### 기능

예측과 정답을 비교해 손실값을 반환한다.

### 동작 순서

1. `forward()`로 예측을 만든다.
2. `cross_entropy_loss()`로 오차를 계산한다.

### `predict(self, x)`

### 기능

테스트용 예측을 만든다.

### 왜 `train=False`를 쓰나?

- Dropout은 테스트 때 뉴런을 끄면 안 된다.
- BatchNorm도 테스트 때는 현재 배치 통계 대신 running 통계를 써야 한다.

### 한 줄 요약

- "여러 레이어를 순서대로 묶어서 하나의 MNIST 분류 모델로 만든 클래스"

## 11. `src/training.py`

이 파일은 학습과 평가를 담당한다.

## `train(model, optimizer, x_train, y_train, epochs=20, batch_size=128)`

### 기능

모델을 실제로 학습시킨다.

### 왜 중요한가?

앞에서 만든 레이어와 함수들이 실제로 연결되어 돌아가는 곳이기 때문이다.

### 한 번의 미니배치에서 일어나는 일

1. `forward`
   - 현재 모델이 예측을 만든다.
2. `loss`
   - 예측이 얼마나 틀렸는지 계산한다.
3. `backward`
   - 어디를 얼마나 고쳐야 할지 gradient를 계산한다.
4. `update`
   - optimizer가 실제 파라미터를 바꾼다.

### 함수 안에서 실제로 하는 일

1. 데이터를 섞는다.
2. 배치 단위로 잘라서 가져온다.
3. `model.forward(x_batch, train=True)` 호출
4. `cross_entropy_loss(y_pred, y_batch)` 호출
5. `dout`를 만들어 `model.backward(dout)` 호출
6. `optimizer.update(model.params, grads)` 호출
7. epoch 평균 loss를 기록한다.

### 반환값

- `loss_history`: epoch별 평균 손실값 리스트

### 한 줄 요약

- "예측 -> 오차 계산 -> 역전파 -> 업데이트를 반복하는 학습 루프"

## `evaluate(model, x, y)`

### 기능

학습이 끝난 뒤 모델 성능을 측정한다.

### 어떻게 동작하나?

1. `model.predict(x)`로 예측한다.
2. 가장 확률이 큰 클래스를 고른다.
3. 정답과 비교해 정확도를 계산한다.
4. 모델 전체 파라미터 개수도 센다.

### 반환값

```python
(accuracy, total_params)
```

### 한 줄 요약

- "이 모델이 얼마나 잘 맞히는지 숫자로 보여주는 함수"

## `plot_loss_history(loss_history)`

### 기능

학습 중 손실값이 어떻게 변했는지 그래프로 보여준다.

### 왜 필요한가?

정확도만 보면 학습이 어떻게 진행됐는지 잘 안 보일 수 있다.  
loss 그래프를 보면:

- 줄어드는지
- 멈췄는지

## 12. 정말 중요한 핵심 개념 4개

처음 보는 사람이라면 아래 4개만 확실히 이해해도 전체 구조가 훨씬 쉬워진다.

## 1. 파라미터(`params`)

모델이 학습하면서 바꾸는 숫자들이다.

예:

- `W1`, `W2`, `W3`
- `b1`, `b2`, `b3`
- `gamma1`, `beta1` 등

이 숫자들이 바뀌면서 모델 성능이 좋아진다.

## 2. gradient(`grads`)

"이 파라미터를 어느 방향으로 얼마나 바꿔야 하는가?"를 알려주는 값이다.

gradient가 있어야 optimizer가 움직일 수 있다.

## 3. `forward`

입력에서 출력까지 가는 과정이다.

쉽게 말하면:

- "지금 내 답은 뭐지?"

를 계산하는 단계다.

## 4. `backward`

출력에서 입력 방향으로 거꾸로 가며 gradient를 계산하는 과정이다.

쉽게 말하면:

- "어디를 얼마나 고쳐야 하지?"

를 계산하는 단계다.

## 13. 이 코드를 읽을 때 추천 순서

처음 읽는 사람에게는 아래 순서를 권장한다.

1. `data.py`
   - 데이터가 어떤 모습인지 먼저 본다.

   - ReLU, Softmax가 어떤 역할인지 이해한다.

6. `optimizers.py`
   - gradient로 실제 값을 어떻게 고치는지 본다.

   - 모든 조각이 어떻게 한 사이클로 연결되는지 본다.

- `optimizers.py`: 파라미터 수정
- `network.py`: 전체 모델 조립
- `training.py`: 학습과 평가 실행
